# BlunderLog

BlunderLog is a chess improvement platform that helps players understand why they lose games, identify recurring mistakes, and train to stop repeating them through a Mistake-to-Mastery loop.

## Core Features

- **Game Ingestion**: Import games from Chess.com public archives or upload PGN files.
- **Chess Analysis**: Stockfish-powered analysis to identify critical positions and mistakes.
- **Mistake Intelligence**: Evidence-backed classification with plain-language explanations.
- **Personalized Training**: Exercises generated from your own game positions.
- **Progress Tracking**: Monitor recurring mistakes and measure improvement over time.
